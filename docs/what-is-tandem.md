# What is Tandem?

Tandem is a Bitcoin protocol for one jointly controlled, evolving object.

Two people create the object together. The active object is represented by an exact native SegWit 2-of-2 output, so both current keys are required for cooperative actions. The pair can add a chapter, rotate one or both keys, or close. If collaboration stops, a recovery transaction prepared in advance can become usable after its relative lock matures.

## The product idea

Most digital objects begin with one owner and treat collaboration as a permission added later. Tandem begins with the pair.

That makes it a natural fit for work, records, and commitments whose meaning comes from shared authorship or stewardship. The object remains one continuous Tandem as its chapters and control pair change.

## What makes it different

### Shared control is structural

Cooperation is not an account setting. The Bitcoin output itself requires the current pair for a cooperative move.

### The history follows exact rules

Every recognized action has a precise transaction shape. Independent implementations can process the same authoritative Bitcoin blocks and reach the same Tandem state.

### Recovery is prepared before progress

The recovery path is not something a service invents during a crisis. The required refund transactions are prepared, signed, exported, and checked before a state-changing parent is broadcast.

### No administrator can rewrite the object

Tandem grants no platform, issuer, content host, or indexer authority to replace keys, change commitments, edit object state, or create supply.

## What Tandem is not

Tandem is not a token, marketplace, governance system, yield product, ranking system, identity proof, or promise of investment value. It does not guarantee recovery from every key-management failure. It does not make external content permanently available.

## Network status

The protocol is finalized. Mainnet is not active. Public activation requires independent verification, recovery drills, signer support, security review, and an explicit launch decision.
